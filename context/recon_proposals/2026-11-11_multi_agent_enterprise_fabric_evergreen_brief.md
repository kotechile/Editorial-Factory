**Decision the reader is facing:** Whether a run's exit is a code-side test — every declared output present, each citing an evidence item from the trace, every derived value replayed — or the model's own claim that it is done, a critic model's opinion, or a step/token/wall-clock budget; and what each of those choices costs on the tasks that cannot be completed at all. It bites the first time a fabric closes a ticket, files a reconciliation or confirms an SAP posting because the agent said "completed", and again the first time a stuck run burns a day of budget and returns a plausible-looking answer.
**Durability:** The mechanism is a property of the contract, not a release: a generative model's statement that it has finished is a token sequence, so "done" can only be verified against artifacts the runtime can check, and no model upgrade changes who is allowed to assert it — the same fabric that ships a 10,007-step default in one official implementation and a 25-step default in the other shows how little the number itself means. The measured rates are **as of** the arXiv revisions cited (evidence-carrying termination v1, 22 Aug 2026; Long-Horizon-Terminal-Bench v3, 9 Oct 2026; BAGEN budget-awareness v1, 29 May 2026; termination poisoning v1, 7 May 2026; semantic early-stopping v1, 25 Jun 2026), and the runtime defaults are as of the vendors' own pages retrieved 2026-11-11 (LangGraph for Python 1.1.4's 10,007 super-steps, LangGraph.js's 25, Temporal's 51,200-event history). The percentages will drift; the rule — declare the outputs, require trace evidence for each, replay the derived values, and keep the budget as the loss bound — does not.

**Thesis:** In an enterprise agent fabric "done" is a claim about evidence rather than a state a model can report, and every cheap substitute for an evidence check has been measured failing in the same direction: a model-driven controller terminated 40 of 66 held-out clusters without support where an evidence-carrying policy terminated 0 of 66 (and its critic core shipped 252 of 288 unsafe completions), 79% of unresolved long-horizon runs end at the wall clock while the agent is still working with mean reward between 0.10 and 0.35, and the model's own infeasibility alarm stays above 70% feasibility until the final 20% of the budget — so the exit has to be a code-side predicate over declared outputs and replayed evidence, with the step and token caps kept only as the bound on what a bad exit costs.
