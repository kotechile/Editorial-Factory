## Prose claims read by eye on the same pages (no row; each rides under the citation above)

- **WorkOS:** "Does the number of end users affect pricing? No, each connection at WorkOS is billed the same, regardless of the identity provider (IdP), directory service used, or the total number of end users." Also: "What's a connection? … Each enterprise customer you support with SSO or Directory Sync is counted as one connection." Directory Sync (provisioning, de-provisioning and role mapping) is priced on the same $125/$100/$80/$65 per-connection ladder as SSO. Audit Logs are a third line item priced "Per SIEM connection $125 / mo" and "Event Retention Per million events stored $99 / mo". The same page prints the comparison line "vs $100 to build it yourself" with no unit and no basis — quote it as the vendor's own one-liner, never as a build cost.
- **Slack:** the plan comparison table's sign-on row reads "OAuth with Google" for Pro, "SAML-based" for Business+, and "Supports Multi-SAML" for Enterprise+, so SAML starts one tier above Pro. Business+ also lists "SCIM user management". Business+ is $18 per user/month paying monthly, $15 paying annually; Pro is $8.75 monthly, $7.25 annually. Both cards currently carry a "50% off for 3 months" promotion — quote list prices, not the promotion.
- **Linear:** Enterprise is "Custom" and "Annual billing only"; the SAML-and-SCIM line sits inside "All Business features +" — so the top self-serve tier ($16) has no sign-on and the tier that does has no published price.
- **Sentry:** "team" is $26/mo "when billed annually with default pre-paid data"; "business" is $80/mo on the same basis and is the first tier listing "SAML + SCIM support (See pricing)" — a flat plan fee with unlimited users, not a per-seat price, so the SSO uplift there is $54/mo regardless of headcount.
- **Arithmetic authorised for the article** (computed from the rows above, not from any source): $125 ÷ $65.38 = 1.91 engineer-hours a month = 22.9 hours a year ("about 23"); $15 − $7.25 = $7.75 a seat a month; $125 ÷ $7.75 = 16.1 seats; 200 seats × $7.75 × 12 = $18,600 a year; $80 − $26 = $54 a month, $648 a year; $65 ÷ $65.38 = about one engineer-hour a month at the 51-100 band.
