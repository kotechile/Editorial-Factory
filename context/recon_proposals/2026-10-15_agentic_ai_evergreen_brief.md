# Evergreen Brief: agentic_ai — 2026-10-15
**Archetype:** evergreen
**Vertical:** agentic_ai
**Persona:** ai_architect
**Decision the reader is facing:** What actually stops an agent run — the step/turn ceiling, the wall clock and the dollar cap — who sets each one, and where the bound has to live so it cannot be overridden by the model it is supposed to be bounding.
**Durability:** The bound is a structural property of the runtime, not a model-version artifact: a loop's stopping condition that is produced by the model is not a bound, and a framework default is a safety net rather than a budget. The structural rule does not expire; every number here is a dated snapshot a reader can re-check — the unbounded-loop census is **as of** arXiv:2607.01641v1 (cs.SE, 02 Jul 2026, 6,549 repositories scanned), the LangGraph graph default is **as of** the version note it carries (1.0.6), and the CrewAI, langchain_core and vendor-tracker figures are **as of** the pages retrieved 2026-10-15. Defaults drift with releases; the rule for setting and asserting your own bound does not.
**De-dup:** `2026-10-12_agent-timeout-false-alarm-budget` is this vertical's nearest prior evergreen artifact — it settles a single tool call's deadline from a stated false-timeout budget (0.1% → p99.9); `2026-10-14_retry-permission-leaves-the-caller` (agentic_resilience_failure) settles who is allowed to retry a failed call. Neither bounds the *run*: this brief decides the termination bound (step ceiling, wall clock, dollars), shows that the inherited default is version- and layer-dependent, and carries the measured census of 68 confirmed unbounded loops — a figure set no prior artifact in this corpus states.
**Thesis:** An agent run needs a bound that lives outside the model and outside the framework's default: in a census of 6,549 agent repositories, 68 confirmed runaway loops were found (91.9% precision), every one of them a missing strong bound, with model-controlled termination a root cause in 26 of the 68 and API cost exhaustion the impact in 65 — while the shipped defaults that are supposed to catch this are a graph recursion limit of 1000 steps on one page, 25 on another, 20 iterations in another framework, and a subagent that silently runs at the framework default instead of its parent's limit.
