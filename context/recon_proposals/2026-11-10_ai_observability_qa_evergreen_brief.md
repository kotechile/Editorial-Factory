**Thesis:** A gate's error rate is set by how often you look, not by the threshold you set: checking a running test after every observation found a "significant" difference 26.1% of the time on identical arms where the threshold promised 5%, ten looks turn a 1.0% dashboard reading into a real 5%, and a 0.95 Bayesian posterior threshold — the usual "we can stop whenever" fix — still declared a winner in 80% of null simulations when it was checked every 100 observations; so if a run may be stopped early, the interval beside the score has to be time-uniform, and the stopping decision has to be a precision rule (keep sampling where uncertainty is highest), which removed 57%–97% of planned trials on a 200-item evaluation without changing the conclusion.
