## Discrepancies and rulings for the drafter

1. **The 200K rule is a footnote, and a gate row cannot carry it.** A cell led `200K — …` evidences on "*you're charged only for requests that return a 200 response code*" earlier on the same page, which is a coincidental window on a real claim. The gate row therefore leads on the **table row's** `$0.72` (row 2, whose evidence window is the Gemini 3.1 Pro Preview line itself); the footnote is quoted verbatim in `## Sources` under [1] and must be attributed to that page in the sentence that carries it. Same class as the eCFR banner-date and nav-digit traps.
2. **Do not write "the bill doubles".** In the verified row the input rate doubles ($3.60 → $7.20) and cached input doubles ($0.36 → $0.72), but output rises 1.5× ($21.60 → $32.40). The honest sentence states each line; the total-request multiplier depends on the reader's input:output mix. A headline or lede that says every token doubles would be false on the output line.
3. **Derived arithmetic, to be recomputed in the final and never copied from the draft prose (it is in neither source):** at Gemini 3.1 Pro rates, 200,000 input × $3.60/M = $0.720, plus 5,000 output × $21.60/M = $0.108 → **$0.828**; at 200,001 input × $7.20/M = $1.440, plus 5,000 output × $32.40/M = $0.162 → **$1.602**, so one token adds $0.774. Trimming 250,000 → 190,000 tokens: $1.800 → $0.684 on the input line (−62% of the input bill for −24% of the tokens). Haiku 5.5: 100,000 × $0.10/M = $0.010 against 100,001 × $0.50/M = $0.050.
4. **The Claude Haiku 5.5 columns are not labelled in the extracted text.** The fetched body prints the two price blocks (up to / over 100,000 tokens) without column headers, so the article may cite the **input** rate ($0.10 → $0.50, the figure the page leads that block with) and may say the same step applies across the block, but must not name the cache-write or cache-read columns from this text. The "fivefold" figure is input only.
5. **The RULER finding is a 2024 measurement.** It covers 17 models evaluated for COLM 2024; the article dates it in the sentence ("in the RULER benchmark … half of the 17 models it tested") and says to re-test on the reader's own documents. It is not a claim about any model shipping in 2026.
