**Decision the reader is facing:** What the fabric returns when a tool call fails — a developer-flavoured instruction ("run this command", "wait before retrying"), a bare status code, or a named call the agent is allowed to make — because that text is the only policy an agent reads at the moment of failure, and it decides whether the run recovers inside the fabric's authority or substitutes a different, riskier tool. It bites every time a gateway author wraps an existing REST API and inherits its error strings, and again the first time a credential expires mid-run against an SAP or Workday endpoint.
**Durability:** The rule is a property of the contract, not a release: an agent at a failure point can only act through the tools it holds, so an error step that names a shell command, a console page or a bare wait is unsatisfiable by construction, and no stronger model fixes an unsatisfiable step — the measured damage grows with capability. The survey counts are **as of** the arXiv v2 of 29 Sep 2026 over 150 servers, the recovery rates are as of the v2 experiments run 24–27 Sep 2026, the problem-details members are as of RFC 9457 (July 2023), and the GitHub rate limits are as of the docs page retrieved 2026-11-18. The exact percentage will drift with the server population; the design rule — the step must be a call in the tool vocabulary, and the retry must name the call to repeat — does not.

**Thesis:** An agent at a failure point can only act through the tools it holds, so the repair step printed in a tool's error is a program the agent runs rather than advice it weighs: in 150 widely used MCP servers 949 of 3,001 error messages carry such a step and 62 of 67 credential steps ask for a terminal command, a configuration change or a web page, which leaves 45% of credential tasks recovered where the server's own login tool named in the same slot leaves 84%, a bare "wait before retrying" leaves 6% where naming the call to repeat leaves 88%, and the loss grows with model capability (18 points on GPT-5.5 to 69 on GPT-6 Astra) — so the fabric's error contract, not its prompt and not its model, is what sets the recovery rate.
