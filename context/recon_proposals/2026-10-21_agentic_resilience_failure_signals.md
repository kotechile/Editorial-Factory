The window's two ends do not point the same way. On 19 October Meta published the production architecture the field is copying: a 1,300-line orchestrator that routes 20+ workflows to 14 isolated specialist agents, does **zero** domain work itself, and exists because a single agent loaded with all the knowledge "started hallucinating" in production after a context threshold — the post's stated reliability wins are context isolation and **contained failures** ("if a subagent fails, the orchestrator retries or escalates"). One day later, a benchmark built from industrial e-commerce workflows and production-log inputs measured the failure class that arrives without failing: a tool returns a schema-valid, plausible, **wrong** value, and across ten current models that roughly halves task success. Recognition is the first bottleneck — the share of rollouts that even notice the bad value runs 20.8% to 33.6% — and the orchestrator in Meta's design is explicitly not the layer that reads domain values. Containment bounds a failure that announces itself; isolation removes the cross-domain context in which a wrong value might have looked wrong.
