**Signal A (Anchor 1):** NVIDIA's own DGX Spark product page and StorageReview's launch report, 2026-10-21 to 2026-10-23 — the vendor publishes a scaling ladder that treats a pair as a bigger machine. The page lists 64GB and 128GB configurations and then: "1x DGX Spark 64 GB … Up to 100B parameters"; "1x DGX Spark 128 GB … Up to 200B parameters"; "2x DGX Spark 128 GB … Up to 200B parameters"; "2x DGX Spark 256 GB … Up to 400B parameters"; "4x DGX Spark 512 GB … Up to 700B parameters", with ConnectX networking that "enables the connection of up to four NVIDIA DGX Spark systems". The 64GB tier "starting at $4,999" is sold "exclusively through Acer, ASUS, Dell, Gigabyte, HP, and MSI from October 23", and NVIDIA's internal numbers for the pair "use Qwen3.8 27B: two clustered 64GB systems delivered up to 1.7x the performance of a single 128GB system" (https://www.nvidia.com/en-us/products/workstations/dgx-spark/ and https://www.storagereview.com/news/nvidia-dgx-spark-64gb-october-23-4999-two-units-cluster-to-128gb).
**Signal B (Anchor 2):** A GB10 reseller's own two-unit measurements and Spheron's price arithmetic, 2026-10-08 to 2026-10-10 — the cable between two units is a 200 Gb/s fabric, not memory: each QSFP112 port is "documented at 200 Gb/s", "the full line rate only appears when traffic runs across both halves", and on the reseller's own two-unit cluster "one cable measured 111.86 Gb/s on a single half and 196.08 Gb/s with both halves carrying traffic", which is "about 25 GB/s" against "the 273 GB/s inside each unit" (https://petronellatech.com/blog/dgx-spark-64gb-specs-price-and-the-cable-to-pair-two). Meanwhile the pair is priced at "about $9,998 for 128GB, or roughly $78/GB" and "a single 128GB unit matches the clustered pair's memory capacity for $3,048 less", with the pooling claim stated as "546 GB/s" and the honest caveat that "clustering adds network-hop latency between the two units that a single unit's internal memory bus doesn't have, so gains on a real model land below the raw bandwidth multiplier" (https://www.spheron.network/blog/nvidia-dgx-spark-64gb-price-specs-and-sync-clustering-2026).
**Emergent Collision Point:** The vendor sells a pair as a bigger machine, and the pair's own wiring says it is two machines behind a narrow link. Put the ladder beside the fabric and the arithmetic neither source states falls out: a 200 Gb/s port is about 25 GB/s, each unit's memory runs at 273 GB/s, so a model whose weights have to cross the cable reads them about eleven times slower than one that fits in local memory. That is why the vendor's evidence for clustering is a 27B model — small enough to sit in one 64GB node, which means the second box is doing parallel work, not holding what the first one cannot. The capacity claim and the speed claim therefore pull in opposite directions: the $9,998 pair reaches the same "up to 200B parameters" ceiling as the $6,950 single unit, and the only thing the extra $3,048 reliably buys is throughput on work that already fits on one node. That is a different purchase from the one the ladder implies, and it needs a different test — whether the model fits one node — before the price is compared at all.
**Hook:** NVIDIA's cheapest route to 128 gigabytes of local memory is two $4,999 boxes and a cable, and the cable is the part nobody priced: it moves data at about 25 gigabytes a second against the 273 gigabytes a second the memory inside each box delivers, so the pooled machine is real capacity on a link eleven times narrower than the memory it pools.
**Tension:** The launch is framed as an on-ramp — a cheaper way to start, with a second box added later — but the two rungs are not the same product. A single 128GB unit reaches NVIDIA's published "up to 200B parameters" ceiling on one memory bus at 273 GB/s; a clustered pair reaches the same ceiling through a fabric that measures about 196 Gb/s, roughly 25 GB/s, because the pooled figure of 546 GB/s is the sum of two local memory buses and not the speed of the link between them. Who this helps: anyone whose workload already fits in 64GB and can be split across two nodes, since NVIDIA's own test puts that pair at up to 1.7x a single 128GB system on a 27B model. Who this hurts: anyone buying the pair specifically to hold a model that does not fit on one node, which is the only reason to want 128GB — they pay $3,048 more than the single unit that reaches the same ceiling, and the weights they bought the extra memory for are the traffic that crosses the narrow link. What it hands the reader: a test to run before the price comparison, and a reason the vendor's 27B benchmark is the right evidence for a different claim than the one the ladder makes.
