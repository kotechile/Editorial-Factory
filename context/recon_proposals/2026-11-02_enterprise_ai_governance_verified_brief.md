**Claims refused for want of a retrievable primary:**
- **A download count for the malicious version.** A secondary blog attributes "roughly 49,000 downloads" to Wiz; Wiz's own post was not fetched in this run. Use the 23 million weekly figure (Datadog, verified) as the base rate and never state how many installs were affected.
- **That LiteLLM is "the most widely used" or "the standard" agent gateway.** Verified wording is "a popular Python proxy library" with about 23 million weekly downloads. Write "one of the most widely installed" at most.
- **Any claim that every enterprise using LiteLLM was compromised.** The report's own scope is unpinned pip installs and four container tags inside the two windows, and the private enterprise registry was unaffected.
- **Any figure for how many enterprises route agent traffic through a gateway.** No fetched source measures it; the article must argue from the guidance's rule, not from a market share.

**Drafter rulings (each one is a real error this class of story produces):**
1. The guidance is **voluntary** and its primary audience is organizations **training or evaluating** highly capable agents. Never call it a mandate, a rule or a requirement for banks; the article's read-across to deployers must be labelled as the document's own "may also apply to deployers" sentence.
2. The **GitHub source tag was clean**. The malicious artifacts were built from a lookalike repository. Never write that "LiteLLM's code was backdoored" — write that its release pipeline was.
3. **104 minutes** is the PyPI window; the container window is **154 minutes**. Show both endpoints (11:39 and 13:23 UTC). Never write "two hours" as if it were measured.
4. The database module **attempted to read** records. Never write that provider keys "were stolen from every proxy".
5. Do not describe the payload as "a vulnerability". It carried **no CVE**; the fix is a pin (1.106.2) and a rebuild, not a patch.
6. Practice 3.3 and 5.3 are quoted exactly as the document writes them; do not paraphrase "tamper-resistant" into "immutable" and do not upgrade "monitored gateway" into "AI firewall".
