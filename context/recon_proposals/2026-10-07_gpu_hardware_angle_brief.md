Corroboration: the SemiAnalysis GPU pricing index put B200 cloud rental at $8.01/GPU-hour in late September, up 79% in three months and now 21% MORE per unit of compute than the older H100 (a reversal from 18% cheaper in June 2026 — https://gpu-index.semianalysis.com/), and getdeploying.com's own price dataset shows on-demand rental prices up 8% over the year, H100 at a $3.47 median across 41 providers (https://getdeploying.com/gpu-price-trends).
**Emergent Collision Point:** Neither leg alone states the inversion. TrendForce says memory *prices* are rising into 2027; the rate cards say cloud *compute* got more expensive this quarter. Put together, they explain the odd result the rental market just printed: because memory — now the scarce, price-setting input — travels with the chip, the newest accelerator has stopped being the cheapest per unit of useful work. The generational assumption ("wait for the next part; it will be cheaper per token") that every AI compute budget was built on quietly broke, and the cost curve turned upward in the one layer most buyers touch directly: the hourly rate.
**Hook:** On October 1, 2026, cloud provider Nebius raised the price of an hour on an NVIDIA H100 by 17% and a B200 by 19% — the same day TrendForce told the market it now expects the high-bandwidth memory inside those chips to cost roughly twice as much per gigabit next year as this year. The chip got no faster. It got scarcer memory, and the bill moved.
**Tension:** For a decade, GPU economics tracked compute: each generation delivered more throughput per dollar, so the rational move was to wait. Memory is now 30–40% of an AI accelerator's bill of materials and the supply of it is finite, so the rental market is pricing memory capacity, not FLOPS. This empowers whoever already owns memory-heavy silicon (and hyperscalers with captive accelerators that dodge Nvidia's repricing) and squeezes everyone renting by the hour — mid-size labs, startups, and any team that set its 2026 inference budget on the old downward curve.
**Target reader:** infra_engineer
**Single claim to defend:** Because HBM is now the constrained, price-setting input in an AI accelerator, the cloud rental market has inverted — renting the newest GPU no longer buys the cheapest unit of compute, and the "each generation is cheaper per unit of work" assumption that AI infrastructure budgets depend on has stopped holding, for reasons set by the memory market rather than the compute market.
